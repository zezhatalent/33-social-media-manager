## Static Data Added

- **Personal Info**: Name, role, tagline, email, phone, location, languages
- **Social Links**: GitHub, LinkedIn, Twitter, Email
- **About**: 2-paragraph professional summary
- **Services**: 6 role-specific services with descriptions and icons
- **Skills**: 5+ skills with proficiency levels and notes
- **Skill Icons**: 4 additional skill categories with icons
- **Statistics**: 4 key metrics with animated counters
- **Experience**: 3 career positions with descriptions
- **Education**: 2+ academic qualifications
- **Certifications**: 4 professional certifications
- **Projects**: 3 featured projects with Unsplash images and tags
- **Cards**: 3 showcase items with metrics and tech stack
- **Awards**: 3 achievements with years
- **Hobbies**: 4 interests with icons
- **Testimonials**: 2 client/colleague quotes
- **Blog Posts**: 2-3 articles with excerpts and read times
- **FAQ**: 4-5 common questions with answers
- **Ticker**: 6 scrolling keywords

## Features

- **Dark/Light Mode**: Manual toggle, persisted to localStorage
- **Mobile Responsive**: Optimized for all screen sizes
- **Animated Background**: Dynamic aurora/particle effects
- **Scroll Animations**: Reveal animations on scroll
- **Interactive Cards**: Hover effects and transitions
- **Typing Effect**: Role typewriter in navbar
- **Smooth Scrolling**: Anchor navigation

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Project Structure

```
src/
├── App.tsx              # Main app composition
├── content.ts           # All static data
├── theme.ts             # Dark/light theme pair
├── Hero.tsx             # Hero section with visual
├── index.css            # Global styles
├── main.tsx             # Entry point
└── components/
    ├── BackgroundFx.tsx # Animated background
    ├── Navbar.tsx       # Navigation with toggle
    ├── Sections.tsx     # All section components
    └── ThemeProvider.tsx # Theme context
```
